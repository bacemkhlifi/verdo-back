# Ocean screening data

`oceans-10m.geojson.gz` is the unmodified GeoJSON ocean layer from Natural Earth,
gzipped for storage. Downloaded 2026-10-27 from:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_ocean.geojson

Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

This is a generalized 1:10 million cartographic map, not a survey. The application
excludes only ocean points farther than 1 km from every polygon ring. Coastal
points and islands rely on detailed OpenStreetMap containment when available.
No inference of agricultural availability is made from the absence of an exclusion.
